error: //apps/web imports //apps/api, which belongs to another app [cross-app-dependency]
 --> apps/web/main.buri:4:6
  |
4 | from "//apps/api" import { greeting };
  |      ^^^^^^^^^^^^ another app

  = code under apps/web/ reaches only that app and packages outside apps/
  = fix: move the code both apps need out of //apps/api into a library under libs/, and depend on that instead

      # apps/web/BUILD.buri
      binary {
          dependencies: ["//apps/api"]
          outputs: [
              { platform: "node" },
          ]
      }

    Everything under apps/<name>/ is one app. An app's packages may depend on
    each other, and on anything outside apps/, such as libs/ and tools/. They
    may not reach another app's packages, whatever its visibility says.

    An import of another app's module is refused at the import. Shared code
    can't reach an app either (`shared-depends-on-app`
    (./shared-depends-on-app.md)), so no path through libs/ gets there.

    Code two apps share belongs in a library under libs/:

      # apps/web/BUILD.buri
      binary {
          dependencies: ["//libs/greeting"]
          outputs: [
              { platform: "node" },
          ]
      }

  --> cmd/page/main.buri:28:26

28 |     let open = lazy.load(fn(c, rows) => editor(c, rows));
   |                          ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ nothing to move into a chunk

   = fix: name a function: `lazy.load(adminPage)`

     Declare the function and hand load its name:

       from "core/io" import * as io;
       from "core/lazy" import * as lazy;
       from "platform/effect" import { Stdout };

       fn admin<C: Stdout>(ctx: C): () {
           io.println(ctx, "admin").ignore()
       }

       fn route<C: Stdout>(ctx: C): () {
           let page = lazy.load(admin);
           page(ctx)
       }

     load moves a function into its own chunk, so it needs a declared function
     to move. A lambda at the call site is part of the surrounding body. A local
     holding a function is a value, and the compiler can't see which body it
     holds. The signature, load<F>(f: F): F, accepts anything, so this check
     does the refusing.

     What to do
     ──────────

     Give the entry the signature its platform fixes.

       Platform               The entry
       LINUX, MACOS, JS, WEB  fn <entry>(): Result<(), Str>
       CLOUDFLARE_WORKER      fn <entry>(request: Request): Response

     No entry declares generic parameters.

     Why
     ───

     The platform calls the entry, so its signature is the platform's to fix. A
     program runs itself and reports how it went: .Ok(()) exits 0, .Err(msg)
     prints msg to stderr and exits 1. A worker is called once per request, so
     the request is the argument and the response is the answer.

     Neither has a call site to infer a type argument from, which is why neither
     declares generic parameters. Neither takes a context either — an entry
     builds the one it needs in its own body.

     An outputs entry says which function is the entry and which platform fixes
     its shape.

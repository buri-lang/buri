    What to do
    ──────────

    If the module declares the name but holds it back, add export to the
    declaration there. If it declares no such name, the spelling is the mistake.
    The diagnostic says which of the two it is, and offers the nearest exported
    name.

    Why
    ───

    A re-export may name only what its module path exports. So a library's
    surface is never wider than the modules it is built from.

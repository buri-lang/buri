   = fix: write `,` here

     What to do
     ──────────

     Write the , where the caret is. The error carries the edit as bytes, so an
     editor's quick fix and buri lint --fix both write it for you. The parser
     then reads the rest of the list rather than abandoning it.

     Why
     ───

     Every comma-separated list in the language separates the same way, with no
     exception for an element that happens to end in a brace. A match arm whose
     body is a block still ends with ,. Without it, A => x followed by -1 => y
     reads as x - 1, and where one arm stops becomes a guess
     (design/grammar-rationale.md 12.12).

     One rule, stated once, also lets the parser tell a missing separator from a
     list that has ended. The next element is already under the cursor, so the
     mistake is one comma and the diagnostic is one sentence.

    An unused type is usually one of three things:

    - A leftover. Delete it, with anything that only supported it: its impl,
    its derive, the constructor nobody calls.

    - Meant to be published. Re-export it from lib.buri. The rule never
    reports a name on the surface. Types under testing/ are measured against
    testing/lib.buri.

    - Meant to be wired in. The code that builds it was never written. Write it.

    A type's own impl and derive blocks don't count as uses, so a dead type with
    ten methods is still dead.

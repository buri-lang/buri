    The message above is the tool's own; only the code is wrong. A tool can't
    invent a catalogue entry, but it can reuse any code the catalogue has, and
    its message then prints under that code.

    A diagnostic with an origin lands at that span of that file. One without
    lands at the start of the file a check was handed, or on the generators
    entry that ran a generate.

    The sentence above is the tool's own. Only the code is this page's: a tool
    cannot invent a catalogue entry, and a code with no page has no wording
    anybody can hold it to.

    A code the catalogue does have prints under that code instead, with the
    tool's own sentence. So a tool can reuse the pages this toolchain already
    writes.

    A diagnostic with an origin lands at that span of that file. One without
    lands on the start of the file a check was handed, or on the generators
    entry that ran a generate.

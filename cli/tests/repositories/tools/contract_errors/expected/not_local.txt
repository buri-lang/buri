  = fix: check the schema in, and name it by a path relative to the tool or a `//` path

    "$schema", and every $ref to another file, names a file in this repository:

      { "$schema": "regions.schema.json" }
      { "$schema": "//schemas/regions.schema.json" }

    A URL, an absolute path, or a relative path that climbs out of the
    repository is refused. Fetching one would put the network in the build, and
    two machines could check one file against two different schemas.

    The one URL known by name is the JSON Schema 2020-12 meta-schema,
    https://json-schema.org/draft/2020-12/schema, which marks a file as a
    schema.

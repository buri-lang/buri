  = fix: drop the `proto` entry from `accepts`, and read the schema's text

      tool {
          generate {
              accepts: [{ language: "proto", type_schema: "config.proto:Config" }]
          }
      }

    A contract hands a tool each input as a value of the contract's root type.
    An input in the proto language is a .proto file, which declares messages and
    holds none, so there is no Config to read out of it.

    Leave proto out of accepts, and generate gets the schema's text.

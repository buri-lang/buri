     What to do
     ──────────

     Build it in main and pass it down as a ctx parameter, or make this a test
     source, where a context may be built per test.

     Why
     ───

     Three places may mint authority: main's body, a test source, and a
     test-only module. A lambda is not one of them, and cannot be — a closure
     able to build a context could hand one to a caller that never named an
     effect, which is exactly what the capture rule exists to prevent.

  = fix: move `..` to the end, as in `[first, ..rest]`; matching a prefix is what an array pattern does

    What to do
    ──────────

    Move .. to the end: [first, ..rest] is legal, [..init, last] is not.

    Why
    ───

    An array pattern matches a prefix and then binds the remainder. Allowing a
    rest in the middle would make matching a search rather than a walk, and the
    cost would be paid on every array pattern in the language.

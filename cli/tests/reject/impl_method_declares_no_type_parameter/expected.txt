   = a call through a bound is checked against the trait's declaration and dispatched to the `impl`'s method, so the two are one signature
   = fix: give `wrap` the signature `Pack` declares

     Why
     ───

     A caller reaching the method through a bound is typechecked against the
     *trait's* declaration, and the code generator reconstructs the impl
     function's type arguments from the trait's. So an impl that took one more
     parameter, or a Str where the trait said Int, would break its promise at
     some later call site, if at all.

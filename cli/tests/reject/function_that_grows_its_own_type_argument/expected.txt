   = fix: where `nest` calls itself, call it at its own type parameters: `nest<T>`

     Each instantiation of a generic function compiles on its own, so nest<Int>
     would need nest<Option<Int>>, then a bigger one, forever. Where a function
     calls itself, directly or through others, pass its own type parameters,
     like count<T> calling count<T>. Swapped is fine too: swap<B, A> inside
     swap<A, B>.

  = `T` carries no bounds, and a bare type parameter has no methods; add a bound that declares `length`
  = fix: add a bound to `T` that declares `length`, or call one the bounds it already carries declare

    Why
    ───

    A method is looked up in exactly one place: the module that declares the
    receiver's type. There is no extension mechanism, so nobody can add a method
    to a type from outside — which is why the fix points a toolchain type at its
    page rather than at an impl block you could not write.

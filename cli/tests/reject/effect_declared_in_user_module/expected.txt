    Move the effect, its wrapper functions and its test implementation into a
    library of their own:

      platform/effect/kv/lib.buri           effect Kv, and get and put
      platform/effect/kv/testing/lib.buri   TestKv

    An effect is authority, so where one is declared is fixed. Effects live
    apart from platforms, so two platforms can offer one effect, and a library
    bounded by it runs on both.

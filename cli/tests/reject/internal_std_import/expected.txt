error: `main` takes `NativeHost`, and the node platform hands its entry a `NodeHost` [entry-host-mismatch]
  --> cmd/internal_std_import/main.buri:11:16

11 | export fn main(host: NativeHost): Result<(), Str> {
   |                ^^^^^^^^^^^^^^^^

   = fix: take `NodeHost`, imported with `from "node" import { NodeHost };` — or build this function for native, and give this output an entry of its own

     What to do
     ──────────

     Take the host of the platform the output names:

       from "node" import { NodeHost };

       export fn main(host: NodeHost): Result<(), Str> {
           .Ok(())
       }

     A program built for two platforms gives each output an entry of its own,
     and both delegate to one function that takes ctx:

       binary {
           outputs: [
               { platform: "native", variant: "linux-arm64" },
               { platform: "node", entries: [
                   { name: "main", function: "mainForNode" },
               ] },
           ]
       }

     Why
     ───

     Each platform offers different effects, so each declares its own host type.
     One entry can't take two.

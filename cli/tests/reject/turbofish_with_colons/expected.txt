   = `::` was needed when `<` in expression position was always a comparison; it no longer is
   = fix: remove the `::`, as in `list.empty<Int>()`

     buri lint --fix and an editor's quick fix remove the :: for you.

     Other languages need :: to tell f<A>(x) from (f < A) > (x). Buri's
     comparison operators don't chain, so the second reading isn't a program
     anyway.

   = a lambda that could close over authority would make the capture rule meaningless
   = fix: thread the context through a `*Ctx` combinator, which passes it in as a parameter instead: `paths.mapCtx(ctx, fn(c, p) => fs.readText(c, p))`

     What to do
     ──────────

     Thread the context through a *Ctx combinator, which passes it in as a
     parameter instead: paths.mapCtx(ctx, fn(c, p) => fs.readText(c, p)).

     Why
     ───

     A closure's type is the whole of what a caller can see about it. A lambda
     that had closed over a context would carry authority behind a type
     mentioning no effect, and the guarantee that a signature says what a
     function may do would hold for every function except the ones written as
     lambdas.

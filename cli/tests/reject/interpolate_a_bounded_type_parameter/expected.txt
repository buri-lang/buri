     A Template names no context, which is why io.println(ctx, "hi ${name}")
     needs only Stdout. So a hole may hold anything the *runtime* can render
     from the type's shape — a primitive, or a value whose Show came from a
     derive, which is that same structural fold — and nothing that has to be
     rendered by calling a function with a context.

     derive Show for Point; in Point's own module admits the hole above, and the

     A hand-written impl Show is the other case, and it stays the author's call:
     show<C: Alloc>(self, ctx: C) names a context the interpolation has no way
     to reach, so write the conversion out.

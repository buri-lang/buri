   = a lambda that could close over authority would make the capture rule meaningless

     What to do
     ──────────

     Thread the context through a *Ctx combinator, which passes it in as a
     parameter instead: paths.mapCtx(ctx, fn(c, p) => fs.readText(c, p)).

     Why
     ───

     A closure's type is all a caller can see about it, so a lambda that closed
     over a context would carry authority behind a type mentioning no effect.

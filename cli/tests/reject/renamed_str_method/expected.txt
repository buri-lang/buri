     What to do
     ──────────

     Check the spelling. If the type is one of yours, declare the method in an
     impl block in that type's own module. If the type ships with the toolchain
     — a Result, an I64 — or belongs to another package, it cannot gain one from
     here, and buri docs <module> lists the methods it has.

     Why
     ───

     A method is looked up in exactly one place: the module that declares the
     receiver's type. There is no extension mechanism, so nobody can add a
     method to a type from outside.

    What to do
    ──────────

    Bind a value whose type has impl Allocator for ....

    Why
    ───

    You declare conformance; the compiler never infers it. A type with all the
    right methods still does not satisfy an effect until an impl says so — which
    is why a test double is a struct with those methods and an impl block.

    What to do
    ──────────

    Write the new path. Nothing else moves — the module has the same exports,
    and the alias is its last segment as it is for every other one:

      from "core/character" import * as character;

      export fn hexDigit(n: Int): Char {
          character.fromDigit(n, 16).withDefault('0')
      }

    Five abbreviations were replaced by the word: core/char is core/character,
    core/num is core/number, core/ordmap is core/orderedmap, core/ordset is
    core/orderedset, and core/proc is core/process. Two modules moved when
    effects left core/: core/effect is platform/effect, and core/host/testing is
    platform/effect/testing.

    Why
    ───

    The old path is gone rather than kept as a second spelling. An alias would
    mean one module with two names, and every reader of an import would have to
    know they were the same — which is the thing a rename is meant to stop.

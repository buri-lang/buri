  = fix: return an `Option` from this function, or turn absence into an error with `.okOr(e)?`

    What to do
    ──────────

    Return a Result from this function, or handle the error here with match or
    withDefault.

    Why
    ───

    ? is an early return of the error, so the function it sits in has to be able
    to return one. If it aborted instead, every ? would be a possible crash.
    This language refuses to have that.

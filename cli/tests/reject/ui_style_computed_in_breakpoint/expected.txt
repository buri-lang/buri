     What to do
     ──────────

     Write the value out, or make it a module-level let, or apply it outside the
     On/At, where it can be an inline style.

     Why
     ───

     A style the compiler cannot evaluate normally degrades to the inline tier,
     which is where Computed already lives. On and At have nowhere to degrade
     *to*: there is no inline form of :hover and none of @media (min-width:
     64rem). Both exist only as rules in a stylesheet, which the compiler writes
     at compile time.

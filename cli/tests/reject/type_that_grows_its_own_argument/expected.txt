   = fix: where `Grow` contains itself, give it its own parameters: `Grow<T>`

     Each instantiation of a generic type compiles on its own, so Grow<Int>
     would need Grow<Option<Int>>, then a bigger one, forever. Where a type
     contains itself, give it its own parameters, like List<T> holding a
     List<T>. Swapped is fine too: Pair<B, A> inside Pair<A, B>.

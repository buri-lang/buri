   = fix: call it on a receiver: `x.area()`; to pass it on, wrap it in a lambda: `fn(x) => x.area()`

     What to do
     ──────────

     Call it on a receiver — x.area() — or, to pass it on, wrap it in a lambda:
     fn(x) => x.area().

     Why
     ───

     The compiler resolves a method through its receiver's type rather than
     looking it up in scope, so sq.area on its own has nothing to evaluate to.
     The lambda turns the receiver into an argument.
